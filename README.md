# AI-Agent-Travel
# AI Travel Agency — автоматизация туристического агентства

## Описание проекта

**AI Travel Agency** — pet-проект по автоматизации бизнес-процессов туристического агентства с использованием **n8n, OpenAI и JavaScript**.

Система моделирует полный жизненный цикл туристического заказа: от сбора требований клиента и формирования индивидуального маршрута до согласования стоимости, имитации бронирования и обработки обратной связи.

Основная идея проекта — объединение возможностей AI-агента с детерминированной бизнес-логикой для автоматизации принятия решений и контроля бизнес-ограничений.

## Основной функционал

- AI-консультант с поддержкой контекста диалога.
- Сбор и валидация требований клиента.
- Проверка выполнимости поездки.
- Подбор отелей, транспорта и экскурсий.
- Формирование индивидуального туристического маршрута.
- Автоматический расчёт стоимости и контроль бюджета.
- Управление версиями и согласование предложений.
- Имитация бронирования и оплаты услуг.
- Генерация документов в Google Docs.
- CRM-интеграция и автоматизация email-уведомлений.
- Обработка инцидентов и претензий.
- Расчёт KPI: CSAT, NPS и финансовых показателей.

## Бизнес-процессы (SG1–SG8)

| Этап | Описание |
|---|---|
| SG1 | Приём заявки и валидация данных |
| SG2 | Анализ требований и предпочтений клиента |
| SG3 | Проверка выполнимости и планирование маршрута |
| SG4 | Подбор туристических услуг |
| SG5 | Расчёт стоимости и согласование предложения |
| SG6 | Имитация бронирования и оплаты |
| SG7 | Подготовка документов и сопровождение поездки |
| SG8 | Обратная связь, расчёт KPI и закрытие заказа |

## Архитектура

Проект реализован на основе гибридной архитектуры:

- **AI-driven Workflow** — обработка запросов на естественном языке, сбор требований и формирование предложений.
- **Rule-based Workflow** — валидация данных, финансовые расчёты, управление состояниями заказа и проверка бизнес-правил.
- **Human-in-the-Loop** — согласование предложений клиентом и участие менеджера в исключительных ситуациях.

AI-агент использует специализированные инструменты:

| Инструмент | Назначение |
|---|---|
| `search_catalog` | Поиск услуг в демонстрационном каталоге |
| `check_feasibility` | Проверка выполнимости поездки |
| `calculate_pricing` | Расчёт стоимости и проверка бюджета |

## Технологический стек

- **n8n** — автоматизация и оркестрация рабочих процессов.
- **OpenAI GPT-5.4-mini** — языковая модель.
- **JavaScript** — реализация бизнес-логики.
- **LangChain / AI Agent** — интеграция LLM и инструментов.
- **n8n Data Tables** — каталог услуг и CRM.
- **Google Docs & Google Drive** — генерация и хранение документов.
- **Gmail** — автоматизация коммуникаций.
- **JSON** — конфигурация workflow.

## Установка и запуск

1. Импортировать JSON-файл в n8n.
2. Настроить OpenAI и Google Credentials.
3. Создать и подключить необходимые Data Tables.
4. Настроить параметры уведомлений.
5. Запустить workflow через Chat Trigger.

## Демонстрационный сценарий

Для проверки полного жизненного цикла туристического заказа используются следующие команды:

```
/demo1
/approve 1
/received
/start
/end
/feedback 5 9
/status
```

Дополнительные сценарии:

- `/demo2` — неполная заявка.
- `/demo3` — конфликт бюджета.
- `/resolve` — устранение конфликта.
- `/reset` — сброс сессии.

## Перспективы развития

- Интеграция с реальными API туристических поставщиков.
- Подключение PostgreSQL.
- Расширение каталога туристических услуг.
- Автоматизированное тестирование и мониторинг.
- Разработка аналитического дашборда.

## Ограничения

Проект представляет собой учебный MVP. Основное демонстрационное направление — Москва → Санкт-Петербург.

Цены, расписания, бронирования, платежи и визовые проверки являются демонстрационными. Реальные бронирования и финансовые операции не осуществляются.
